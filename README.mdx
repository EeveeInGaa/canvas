# README Canvas

An Obsidian-inspired canvas with React.

To start the application, run `pnpm dev` and open http://localhost:5173/.

---

## Features

- coordinate system
- zoomable canvas
- panning
- drawing
- text and link type
- grouping
- jump to canvas
- duplicate, delete
- snap to grid
- debug mode
- multiselect
- keyboard movement
- undo/redo
