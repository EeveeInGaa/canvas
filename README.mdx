# README Canvas

An Obsidian-inspired canvas with React.

---

## Features

- coordinate system
- zoomable canvas
- panning
- drawing
- text and link type
- grouping
- jump to canvas
- duplicate, delete
- snap to grid
- debug mode
- multiselect
- undo/redo
